# 设计原则

GrMine UI 的设计植根于四个核心理念，贯穿每一个组件与设计决策。

## 間（Ma）—— 留白之美

間（Ma）是日本美学中对"空间"的理解。在 GrMine UI 中，留白不是空白，而是呼吸。

- 组件之间保持充裕的间距，让内容自然流动
- 避免视觉拥挤，每个元素都有存在的空间
- 间距遵循 4px 基础网格，形成节奏感

## Precision —— 精密

受瑞士排版与网格系统启发，追求精确与秩序。

- 严格的排版层级：标题、正文、辅助文字各司其职
- 基于网格的间距系统，确保视觉对齐
- 每个组件的尺寸、圆角、阴影都经过精确计算

## Warmth —— 温暖

在极简中注入温度，用微暖的灰色替代冷调中性色。

- 中性色偏暖，营造柔和舒适的阅读体验
- 强调色克制使用，仅在需要引导注意时出现
- 交互反馈温和而非突兀

## Restraint —— 克制

只提供必要的，不多也不少。

- 组件 API 精简，避免过度配置
- 视觉装饰最小化，内容优先
- 不提供过多变体，每种变体都有明确的使用场景

---

这四条原则相互支撑：留白赋予精密以呼吸，温暖柔化克制的冷峻，克制让留白成为可能。
