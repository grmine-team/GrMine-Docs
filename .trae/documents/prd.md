## 1. 产品概述

GrMine Docs 是一个面向开发者的多项目文档中心，用于集中管理和展示多个项目的开发文档。站点采用 GrMine UI 作为视觉基础，部署在 GitHub Pages 上，为开发者提供清晰、优雅的文档阅读体验。

- 核心目标：为多个项目提供统一的文档托管平台，支持按项目分类浏览文档
- 目标用户：使用 GrMine 系列项目的开发者

## 2. 核心功能

### 2.1 功能模块

1. **首页**：项目总览，展示所有项目卡片，快速导航到各项目文档
2. **项目文档页**：左侧边栏导航 + 右侧文档内容，支持 Markdown 渲染
3. **全局搜索**：快速搜索文档内容，跨项目检索

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 项目卡片网格 | 展示所有项目，每个卡片包含项目名、描述、标签、最近更新时间 |
| 首页 | 顶部导航栏 | Logo、项目切换、主题切换、搜索入口 |
| 项目文档页 | 侧边栏导航 | 按分类展示当前项目的文档目录树，支持折叠展开 |
| 项目文档页 | 文档内容区 | Markdown 渲染，支持代码高亮、表格、链接等 |
| 项目文档页 | 面包屑导航 | 显示当前文档路径 |
| 项目文档页 | 上一页/下一页 | 文档间快速切换 |

## 3. 核心流程

用户访问首页 → 浏览项目列表 → 点击进入某项目 → 通过侧边栏选择文档 → 阅读文档内容 → 通过面包屑或导航切换文档

```mermaid

    "阅读文档内容" --> "面包屑导航"
    "面包屑导航" --> "侧边栏选择文档"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：GrMine UI 的 accent 蓝（`--gm-accent`）+ 暖灰中性色
- 按钮风格：圆角、轻阴影，遵循 GrMine UI 的 `.gm-btn` 规范
- 字体：Outfit（标题）+ IBM Plex Sans（正文）+ JetBrains Mono（代码）
- 布局风格：左侧固定侧边栏 + 右侧内容区，顶部粘性导航栏
- 图标风格：Lucide Icons 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | Hero 区域 | 大标题 + 副标题 + 搜索框，渐变背景 |
| 首页 | 项目卡片网格 | 3列网格，每个卡片含项目图标、名称、描述、标签、更新时间 |
| 项目文档页 | 侧边栏 | 固定宽度 14rem，分类标题 + 文档链接列表，当前项高亮 |
| 项目文档页 | 内容区 | 最大宽度 48rem 居中，Markdown 排版，代码块带语法高亮 |
| 项目文档页 | 面包屑 | 文档路径，可点击跳转 |

### 4.3 响应式

- 桌面优先设计
- 移动端：侧边栏收起为抽屉菜单，项目卡片变为单列
- 平板：侧边栏可折叠，项目卡片双列

### 4.4 暗色模式

- 完整支持 GrMine UI 的 `data-theme="dark"` 暗色模式
- 主题切换按钮在导航栏右侧
- 自动检测系统偏好并持久化用户选择
